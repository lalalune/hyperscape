```
"A heroic medieval knight character with polished silver plate armor,

```

**Step 3: Meshy 3D Generation** (AI 3D Modeling)
```
Meshy.ai Input: Enhanced prompt + optional reference image
Meshy.ai Output: High-quality GLB file (30K polygons, PBR materials)
Time: 6-8 minutes
```

**Step 4: VRM Conversion** (Automated Processing)
```
VRMConverter.ts:
- Extract skeleton (detect bones)
- Normalize height → 1.6m
- Map bones → VRM HumanoidBone standard
- Fix coordinate system (Y-up)
- Add VRM 1.0 extensions
- Export VRM GLB
Time: 2-5 seconds
```

**Step 5: Animation Retargeting** (Instant Animation Library)
```
AnimationRetargeting.ts:
- Load Mixamo animation (walk, run, idle, combat, emotes)
- Retarget to VRM skeleton
- Bind pose compensation
- Scale adjustments
Result: 1000+ animations available instantly
```

**Final Output:**
- ✅ `medieval-knight.vrm` (game-ready VRM 1.0 file)
- ✅ Works in VRChat, VSeeFace, VTube Studio, Hyperscape, Unity, Unreal
- ✅ Fully animated (1000+ Mixamo animations)

✅ **glTF 2.0 Base** (Industry-standard 3D format)

**HumanoidBones Mapped:**

- **Core Skeleton**: 24 bones (hips, spine, chest, head, arms, legs)
- **Optional Fingers**: 48 additional bones (full hand rig)
- **Optional Toes**: 4 additional bones
- **Total**: Up to 76 bones supported

**Coordinate System:**

- ✅ Y-up (VRM standard)
- ✅ Right-handed coordinate system
- ✅ Units in meters
- ✅ 1.6m height normalized

**Skeleton Requirements:**

- ✅ T-pose bind pose (or auto-converted from A-pose)
- ✅ Height normalized to 1.6m VRM standard
- ✅ Hips local position set (game engine compatibility)
- ✅ Inverse bind matrices calculated

**glTF 2.0 Features:**

- ✅ Binary GLB format (compact, efficient)
- ✅ PBR materials (Physically-Based Rendering)
- ✅ Quad topology (clean geometry from Meshy)
- ✅ Skinning with bone weights (smooth deformation)

**Animation Compatibility:**

**Animation Features:**

### **B. Technical Deep-Dive**

**VRM Conversion Process**:
1. Parse Meshy GLB (Three.js GLTFLoader)
2. Extract skeleton (SkinnedMesh.skeleton)
3. Map bones (Meshy → VRM HumanoidBone)
4. Normalize height (1.6m standard)
5. Fix coordinate system (Y-up)
6. Validate T-pose (or convert from A-pose)
7. Add VRM 1.0 extensions (VRMC_vrm)
8. Export GLB with VRM metadata

**Animation Retargeting Algorithm**:
1. Load Mixamo animation (GLTFLoader)
2. Detect bone names (mixamorig: prefix)
3. Map to VRM bones (dictionary lookup)
4. Apply bind pose compensation (quaternion transforms)
5. Scale positions (rootToHips adjustment)
6. Generate new AnimationClip (VRM-targeted)

**Performance Optimizations**:
- Lazy loading animations (on-demand)
- Texture compression (KTX2/Basis)
- Geometry LOD (future)
- Worker threads for conversions (future)

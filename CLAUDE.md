# Hyperscape-5 Project Memory

This is the main memory file for the Hyperscape-5 project. It uses imports to keep information modular and organized.

## Project Overview

- Hyperscape-5 is a 3D multiplayer game engine with AI agent integration
- Asset-forge is the primary package for 3D asset management and generation
- Uses Drizzle ORM + PostgreSQL, Elysia API framework, Privy authentication
